# ICRA 2028 website

Static HTML and CSS website for the International Conference on Representations of Algebras 2028.

## Files

* `index.html` — main page content
* `header.html` — navigation
* `footer.html` — footer and contact details
* `style.css` — colours and layout

## Local preview

Run:

`python3 -m http.server`

Then open `http://localhost:8000` in a browser.
